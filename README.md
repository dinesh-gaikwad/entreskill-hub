## 🌟 About
micro-business  entrepreneurship  startup  skill-development
business-roadmap  mentorship  india  self-employment
EntreSkill Hub helps aspiring micro-entrepreneurs discover business ideas aligned with their skills, and provides structured roadmaps, training content, and mentorship access to launch and grow their ventures.

### The Problem
Millions of people have valuable skills (tailoring, cooking, handicrafts, digital skills) but lack structured guidance to turn them into businesses.

### Our Solution
A web platform that:
- Matches your skills to business opportunities
- Provides step-by-step business roadmaps
- Offers curated training resources
- Connects you with expert mentors

## ✨ Features

- 🎯 **Skill Assessment** – Profile your skills and interests
- 💡 **Business Idea Engine** – 500+ curated ideas matched to you
- 🗺️ **Business Roadmaps** – Step-by-step launch guides
- 📚 **Training Library** – Videos, articles, checklists
- 👨‍🏫 **Mentor Connect** – 200+ verified expert mentors
- 📊 **Progress Dashboard** – Track your entrepreneurship journey

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Fonts**: Syne + DM Sans (Google Fonts)
- **Deployment**: Vercel
- **SEO**: Schema.org, Open Graph, sitemap.xml

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/entreskill-hub.git

# Navigate into directory

# Open in browser (no build needed!)
open index.html
```
